# ResumeForge

Free, privacy-first resume, CV and portfolio builder. Single HTML file, no build step, no server. Your data stays in your browser.

## Features
- Three modes: Resume, CV, Portfolio
- 14 layouts x 10 colors x 4 fonts x 2 densities (1,120 template combinations)
- ATS checker with job-description keyword matching and an ATS-safe rating per template
- Print / Save as PDF, copy plain text

## Use
Open `index.html` in any browser, or deploy with GitHub Pages (workflow included).
